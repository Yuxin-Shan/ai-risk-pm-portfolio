# 阶段 4 · 设计基线

> 阶段 4 主控(DSH)主导。本文档是全部 14 个界面的视觉唯一依据;两版样张(深色监控台 / 浅色业务后台)共用同一套语义 token,仅换皮肤值。
> 状态:基线定稿,待评审。
> 数据说明:全部为模拟数据。

---

## 一、核心决策:一套 token,两套皮肤,一个产品一种风格

- 用户给的是**两版候选风格**——深色监控台(作战室)vs 浅色业务后台(企业后台),最终**整产品选其一**,不是「在线侧深、工作台浅」的双风格并存。
- 因此本基线只定义**一套语义 token**(颜色、字号、间距、圆角、组件),皮肤层用 CSS 变量切换 `?theme=dark|light`。
- 理由:14 个界面必须风格一致;深色监控台与浅色后台的差距只是「皮肤值」,不是「两套设计」。
- 样张页面 = **对话窗口**(工作台主界面),同一份 DOM,只切皮肤,直接回答「成品会比线框好看得多,而且两种风格都成立」。

### 1.1 两版风格定位

| | 深色监控台 | 浅色业务后台 |
|---|---|---|
| 气质 | 作战室 / 监控大屏 | 企业后台 / 运营台 |
| 底色 | 近黑藏青 | 冷灰白 |
| 强调方式 | 高对比 + 霓虹状态色 + 卡片描边 | 白卡片 + 轻阴影 + 克制的语义色 |
| 信息密度 | 高(面板栅格) | 中高(卡片 + 紧凑表格) |
| 适合讲的故事 | 「实时链作战」「可观测」「日志回放」 | 「运营台日常」「实验迭代」「可审计」 |

| `--text-1` | `#141B2B` | `#E7EEF9` | 主文字 |
| `--text-2` | `#46536A` | `#A6B4C9` | 次级文字 |

### 2.2 状态色语义(自检第 2 关「系统状态可见性」的底座)

| 状态 | 色 | 一眼可辨的口径 |
|---|---|---|
| 成功 / 通过 / 已生效 / 放行 | 绿 | 门禁过、注册生效、任务成功 |
| 警示 / 挂起 / 待确认 | 琥珀 | 临时管控「已挂起」、待确认卡片 |
| 失败 / 阻断 / 拦截 / 未过 | 红 | 工具失败、任务失败、门禁未过、裁决拦截 |
| 处理中 / 执行中 / 调查中 | 蓝 | 进度条、案件调查中 |
| 灰度中 / 待审批 / 待授权 / 待注册 | 紫 | 待注册包、工具授权包、灰度中 |
| 停用 / 未授权 / 无数据 | 灰 | 未授权工具置灰、空态 |

> 关键区分:蓝 =「正在发生」,紫 =「等人经手」,琥珀 =「需关注/被挂住」。演示脚本会点名「灰度中 / 审批中 / 失败态」,这三个状态在界面上必须有可读的颜色标签。

### 2.3 图表色(与状态色分层,不混用)

数据可视化连续色:蓝 `#2E6BE6` → 紫 `#7C5CFC` → 青 `#12B39A` → 琥珀 `#E0A93C` → 玫红 `#E05FA0`(深色主题下提亮一档)。状态点永远用 §2.2 的语义色,折线/柱不用红绿表达好坏。

## 三、字体层级

| 层级 | 字号 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| H1 页头 | 22 | 600 | 1.3 | 页面标题 |
| H2 区块 | 16 | 600 | 1.4 | 卡片标题/区块标题 |
| H3 小组件 | 14 | 600 | 1.4 | 消息标题/字段标签 |
| 正文 | 14 | 400 | 1.55 | 主体内容 |
| 辅助 | 13 | 400 | 1.5 | 表格单元格/说明 |
| 弱化 | 12 | 400 | 1.5 | 时间戳/脚注/占位 |
| 指标大数字 | 24–28 | 600 | 1.1 | 指标卡 |

- 字体栈:`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`。
- 数字统一 `font-variant-numeric: tabular-nums`,指标/编号/时间对齐。
- 不引网络字体,保证离线打开与截图时不回退。

## 四、间距与圆角

- 间距 4px 基数:4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- 页面内边距 24,卡片内边距 16–20,卡片间距 12–16,表行高 40。
- 圆角:控件 6,输入框 8,卡片 10,对话框/大卡 12。
- 阴影:浅色用 `0 1px 2px rgba(16,24,40,.04), 0 4px 12px rgba(16,24,40,.06)`;深色不用阴影,改用 1px 描边 + 面板色阶分层(深色监控台无阴影更「硬」)。

## 六、图标方案

- **Lucide**(inline SVG,MIT/ISC):笔画风格,`stroke-width: 1.5`,尺寸 16 / 20 两档,颜色用 `currentColor` 跟随文字色,两套皮肤通用。
- 常用图标内联进页面,零外链:消息、实验(beaker/flask)、机器人(bot)、工具(wrench)、队列(list)、证据链(git-branch/timeline)、报告(file-text)、日志回放(rewind)、监控(activity)、策略(shield)、模型(box)、数据集(database)、搜索、设置、加号、箭头。
- 备选:Phosphor(同风格、更全),若内联图标不够再引入。
