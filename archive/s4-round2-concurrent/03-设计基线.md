# 阶段 4 设计基线

> 本文档定义阶段 4 全部界面的视觉与组件规范,是两版风格样张与最终 14 页面原型的共同依据。
> 结论先行:**一套语义 token、两套皮肤(深色监控台 / 浅色业务后台)、7 态状态徽章、4 档字号、4px 间距节奏、约 30 枚内联 SVG 图标、约 25 个组件。样张用「对话窗口」页面把两套皮肤做出来供选型;选定后全量页面只换皮肤不换结构。**

## 一、风格方向

**定位:演示级企业 SaaS 质感 —— 中性、专业、密度中高,不做营销页式的花哨。**

| 原则 | 说明 |
|---|---|
| 观感目标 | 第一眼是「正经运营台」,不是「AI 生成的炫技页面」。克制使用渐变与阴影,靠网格、间距、状态色说话 |
| 深浅两皮肤 | 深色版对标监控台(Datadog 式:壳深、图表主导);浅色版对标业务后台(Stripe 式:白底、卡片分明)。**同一套 DOM 与组件,只换 token 值** |
| 深度表达 | 深色皮肤:边框 + 色阶分层,卡片基本不投影;浅色皮肤:细边框 + 极浅投影(0 1px 2px 6% 黑) |
| 密度 | 对话窗口中等密度(读起来像聊天但携带运营信息);监控/队列/记录类页面中高密度(表格行高 32px 起) |
| 与线框的关系 | 结构沿用阶段 3 线框(三栏对话结构、帧态),视觉全部重做 —— 回答用户「成品会不会和线框一样丑」:不会,线框只锁定结构与交互帧 |

**产品名占位(待评审):** 顶栏产品名用中性占位「**AI 风控工作台**」+ 盾形标识,不虚构品牌名;页面角标「演示数据 · 模拟」常驻。若评审希望有名字,再另行提案。

## 二、配色规范

### 2.1 语义 token(两套皮肤的值)

| Token | 用途 | 深色 · 监控台 | 浅色 · 业务后台 |
|---|---|---|---|
| `--bg` | 应用壳底色 | `#0B0E14` | `#F4F6FA` |
| `--surface` | 面板/卡片底 | `#11151F` | `#FFFFFF` |
| `--surface-2` | 浮起层(卡片上卡、hover、输入底) | `#171D2A` | `#F7F9FC` |
| `--border` | 常规分隔线 | `#232B3A` | `#E3E8F0` |
| `--border-strong` | 强调分隔(卡片描边、焦点) | `#33415A` | `#C9D3E2` |
| `--text-1` | 主文字 | `#E8EDF5` | `#16202E` |
| `--text-2` | 次级文字 | `#9AA6B8` | `#55627A` |
| `--text-3` | 弱化/占位 | `#5F6B80` | `#94A0B5` |
| `--accent` | 主色(品牌/主按钮/选中) | `#3D8BFF` | `#2E6BFF` |
| `--accent-hover` | 主色悬停 | `#5BA0FF` | `#1F5CFF` |
| `--accent-tint` | 主色浅底(选中态、气泡底) | `rgba(61,139,255,0.12)` | `rgba(46,107,255,0.08)` |
| `--shadow-card` | 卡片投影 | 无(边框分层) | `0 1px 2px rgba(16,24,40,0.06)` |

**主色决策:** 蓝。理由:风控运营台需要「冷静、可信」,蓝色是监控/风控领域的通行主色;紫色(如 Datadog)品牌感过强,不适合中性作品集。深色版的蓝在深底上提亮一档(对比度)。

### 2.2 状态色(7 态,两套皮肤共用色相、按皮肤微调亮度)

| 状态 | 色相 | 深色值 | 浅色值 | 用途 |
|---|---|---|---|---|
| 成功 / 通过 / 放行 | 绿 | `#34C77B` | `#16A34A` | 任务成功、门禁通过、裁决放行 |
| 处理中 / 调查中 / 执行中 | 蓝 | `#3D8BFF` | `#2563EB` | 执行中、调查中、重试中(可配脉冲点) |
| 警示 / 告警 | 琥珀 | `#F5A623` | `#D97706` | 看板告警、队列积压 |
| 待确认 / 审批中 / 待授权 | 琥珀 | `#F5A623` | `#D97706` | 待确认卡片、审批中、待授权(配时钟图标) |
| 失败 / 拦截 / 拒绝 | 红 | `#F0526A` | `#DC2626` | 任务失败、裁决拦截、注册拒绝 |
| 灰度中 | 紫 | `#A78BFA` | `#7C3AED` | 灰度发布、实验对照 |
| 停用 / 排队 / 未知 | 灰 | `#6B7486` | `#64748B` | 已停用、排队中、无数据 |

**两条口径(来自调研 §三):** 红同时承担「拦截(业务裁决)」与「失败(系统状态)」,靠徽章文案与图标区分;琥珀同时承担「警示」与「审批中」,语义同为「需要人关注」,不冲突。

**徽章形态:** 点状(仅色点,用于行内)与胶囊(色点+文字+浅色底 `color-mix` 10% 透明)两种;所有状态徽章共享 `--badge-*` 派生 token,改皮肤只改 7 个色值。

### 2.3 图表分类色板(固定顺序,不挪用状态色 —— Datadog 原则)

当一图多序列(对比、分布)时,按固定顺序取色:**蓝 `#3D8BFF` → 紫 `#A78BFA` → 青 `#2BB5B2` → 琥珀 `#F5A623` → 红 `#F0526A` → 灰 `#6B7486`**(浅色版同序调暗)。状态绿绝不进分类序列。

## 三、字体层级

| 档 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| H1 页标题 | 20px / 28px | 600 | 页面主标题 |
| H2 区块标题 | 16px / 24px | 600 | 卡片标题、计划卡标题 |
| H3 小标题 | 14px / 22px | 600 | 表格分组、面板 eyebrow |
| 正文 | 13px / 20px | 400 | 对话正文、表格正文、表单 |
| 辅助 | 12px / 18px | 400 | 注释、时间戳、徽章、表头 |
| 指标大数 | 24px / 32px | 600 | KPI 瓦片数字 |

**规则:**

1. 字体栈:`-apple-system, "SF Pro SC", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`(零加载,见工具链调研)。
2. **所有指标、表格数字、时间戳:`font-variant-numeric: tabular-nums`**,数字右对齐。
3. 编号/ID/代码(如 `EXP-2317`、`TR-88213`、`v2.3.1`):系统等宽栈 `ui-monospace, "SF Mono", Consolas, monospace`,11–12px。
4. 字重只用 400/500/600/700,不斜体(中文无斜体惯例)。

## 四、间距节奏与几何

| 项 | 值 |
|---|---|
| 间距基准 | 4px;档位 4 / 8 / 12 / 16 / 20 / 24 / 32(监控页允许 40/48) |
| 圆角 | 控件 6px、卡片 8px、弹层 10px(不再大) |
| 表格 | 行高 32px(密集表)、36px(宽松表);发丝分隔线;表头 sticky、12px 等宽大写感(中文不用大写,用 12px + 字重 600) |
| 图标 | 24×24 网格、1.6px 描边、圆头端点;行内 14px 渲染 |
| 页面骨架 | 顶栏 48px + 左导航 216px + 内容区;对话窗口三栏:导航 216 + 对话流(自适应,最大 780)+ 右侧栏 300 |

## 六、图标方案

- **来源:** 内联 SVG,按 Lucide 几何风格手绘(24×24 网格、1.6px 描边、圆头、`stroke="currentColor"`),不引第三方文件(见工具链调研)。
- **首批 30 枚:** 盾(风控)、消息方框(对话)、烧瓶(实验)、机器人(Agent)、扳手(工具)、层叠(任务队列)、链条(证据链)、文件对勾(验证报告)、回放(日志回放)、数据库(数据集)、仪表(策略)、折线监控(监控)、芯片(模型)、名单(列表)、星火(特征)、时钟(审批)、三角告警、圆圈对勾、圆圈叉、刷新(重试)、暂停、发送、@、回形针、搜索、右箭头、外部链接、点、警示盾、半亮圆(灰度)。
- **颜色:** 一律 `currentColor`,随文字色;状态图标才用状态色。
- **落地:** 每页 HTML 内嵌一个 `<svg style="display:none"><symbol id="i-xxx">…</symbol></svg>` 图标库 + `<use href="#i-xxx">`,14 页复制同一段,保持零外链。

## 七、异常态与系统状态可见性(启发式 #1 落点)

| 状态 | 徽章 | 至少出现在 |
|---|---|---|
| 执行中 / 调查中 | 蓝 · 脉冲点 | 对话窗口进度卡、任务队列、案件详情(调查轨迹) |
| 待确认 / 审批中 | 琥珀 · 时钟 | 对话窗口待确认卡、模型服务审批面板、工具台授权包 |
| 灰度中 | 紫 | 模型服务列表、实验管理对照组、策略引擎配置版本 |
| 失败 | 红 · 叉 | 对话窗口异常卡、任务队列、日志回放 |
| 已打断 / 暂停 | 灰 · 暂停图标 | 对话窗口进度条暂停态 |
| 排队中 | 灰 · 点 | 任务队列 |
| 空态 / 无数据 | 灰 | 全部列表页 |

**规则:任何一步执行,界面上必须能同时看到「在做什么」与「处于什么状态」;灰化的对象必须写明原因与去处(如未授权工具置灰 +「去生成授权包」)。**

## 八、数据标注规范(诚实红线落点)

1. **文件头:** 每个 HTML 顶部注释:本页面数据均为虚构模拟数据,仅用于演示产品流程。
2. **演示页:** 右下角常驻「演示数据 · 模拟」胶囊(组件 25)。
3. **数据表:** 《模拟数据说明》(Honnold 起草)表格头标注模拟;样张与原型里出现的每个数字,后续必须能在口径表(M-01…M-20)或《模拟数据说明》中找到出处。
