## 一、风格方向

一句话:**「监控台的纪律 + 业务后台的克制」,靠语义化 token 同时支撑两套皮肤。**

| | 深色监控台版(Dark) | 浅色业务后台版(Light) |
|---|---|---|
| 定位 | 实时链、监控、回放等「值守态」界面 | 工作台、配置、列表等「作业态」界面 |
| 气质 | 高对比、高密度、状态点醒目、等宽数字 | 留白、细边框、单一强调色、整齐 |
| 底色 | 近黑蓝 `#0B1020` | 冷灰 `#F6F8FB` |
| 强调 | 电光蓝 + 青 | 靛蓝 |
| 结构方式 | 边框 + 微弱内发光 | 1px 细边框 + 极浅阴影 |
| 参照 | Datadog | Linear + Stripe Radar |

**两版共用同一套语义 token 名**,同一份 HTML 只切 `data-theme`。这样「先样张、后铺开」返工最小 —— 用户选定风格后,其余 13 个界面只需照同一份 token 写。

## 二、配色规范(语义 token)

### 2.1 中性色(表面/文字/边框)

| token | Dark | Light | 用途 |
|---|---|---|---|
| `--bg` | `#0B1020` | `#F6F8FB` | 页面底色 |
| `--surface` | `#111828` | `#FFFFFF` | 卡片/面板 |
| `--surface-2` | `#182136` | `#F1F4F9` | 嵌套面板/表头/hover |
| `--surface-3` | `#1F2A42` | `#E8EDF5` | 输入框底/选中态 |
| `--border` | `#26314B` | `#E3E8F0` | 1px 分割 |
| `--border-strong` | `#34405E` | `#CBD4E3` | 强调边框/输入框描边 |
| `--text` | `#E9EEF8` | `#17202E` | 主文字 |
| `--text-2` | `#A7B1C6` | `#5A6A82` | 次级文字 |
| `--text-3` | `#6B7690` | `#93A0B4` | 弱文字/占位 |
| `--accent` | `#5B8CFF` | `#3B6FE0` | 主强调/主按钮/当前导航 |
| `--accent-soft` | `rgba(91,140,255,.14)` | `rgba(59,111,224,.10)` | 强调底/选中行底 |
| `--cyan` | `#2DD4BF` | `#0E9F8A` | 次强调(Agent/在线态点缀) |

### 2.2 状态色(语义状态 —— 硬约束,不可混用)

| 语义 | token | Dark | Light | 用途 |
|---|---|---|---|---|
| 成功 / 已裁决 / 达成 | `--ok` | `#34D399` | `#16A34A` | 门禁达成、任务成功、裁决结论 |
| 警示 / 待确认 / 待人工 | `--warn` | `#F5B84D` | `#D97706` | 待确认卡片、积压告警、待人工介入 |
| 失败 / 阻断 | `--danger` | `#F87171` | `#DC2626` | 工具失败、任务失败、未授权调用>0 |
| 处理中 / 执行中 | `--info` | `#60A5FA` | `#2563EB` | 执行中、受理中、队列执行中 |
| **灰度中 / 金丝雀** | `--canary` | `#A78BFA` | `#7C3AED` | 灰度发布、金丝雀版本、待注册 |
| 停用 / 禁用 / 缺失 | `--muted` | `#64748B` | `#94A3B8` | 停用工具、未授权、证据缺失步骤 |

> **「灰度中」= 紫,与「处理中」的蓝、与「停用」的灰严格区分。** 这是「系统状态可见性」验收(AC-03/AC-14 及阶段 4 自检第 2 关)的关键;状态点颜色 + 文字标签双通道呈现,不依赖单一颜色。

### 2.3 深浅两版截图用色纪律

- 深色版:状态色用「亮化」档(在深底上保持 ≥4.5:1 可读性),正文不压纯白(用 `#E9EEF8` 降一点刺眼)。
- 浅色版:状态色用「加深」档,白卡上不出现大面积高饱和色块,只做「色点 + 文字 + 少量底色」。

## 三、字体层级

**字族**:系统栈(见《02》2.2);指标数字用等宽栈。

| 层级 | 字号/字重 | 行高 | 用途 |
|---|---|---|---|
| Display | 20px / 700 | 1.3 | 页面标题、大卡主数字 |
| Title | 16px / 600 | 1.4 | 卡片标题、区块标题 |
| Body | 14px / 450 | 1.55 | 正文、表格、按钮 |
| Sub | 13px / 500 | 1.5 | 辅助说明、参数、时间戳 |
| Caption | 12px / 500 | 1.4 | 标注、状态 chip、图表轴 |
| Mono | 13–16px / 500 | 1.4 | 指标值、案件/任务/包编号、时间 |

编号/指标统一等宽,营造「可审计、可复算」的仪表感(对齐 M 口径「每个数字可复算」)。

## 四、间距节奏

**4px 基准**,按 4 的倍数走,不出现非 4 倍数的间距:

| 档 | 值 | 用途 |
|---|---|---|
| 1 | 4px | 图标与文字、chip 内边距 |
| 2 | 8px | 列表行内、标签间距 |
| 3 | 12px | 卡片内紧凑间距 |
| 4 | 16px | 卡片内边距、表单项间距 |
| 5 | 20px | 区块间距 |
| 6 | 24px | 卡片间距、页面主间距 |
| 7 | 32px | 大区块分隔 |
| 8 | 40/48px | 页面级留白、侧栏宽 |

**圆角**:小控件 6px、卡片 10px、大卡/弹层 12px。
**阴影**:浅色版 `0 1px 2px rgba(16,24,40,.06)` 极浅;深色版基本靠边框 + `0 0 0 1px` 结构,少用外发光。

## 五、布局与导航(信息架构的视觉落地)

- **左侧栏**固定 220px(可收起到 56px 图标态):分「在线风控侧」「AI 工作台」两组,当前项 = 强调色 + 左侧 2px 指示条 + `--accent-soft` 底。
- **顶部栏** 48px:左侧当前页名 + 面包屑,右侧状态区(时间窗 / 数据延迟 / 环境标注)。
- **主内容区**:监控台类用多列网格;操作台类用「左对话流(自适应)+ 右对象栏 300px」。
- **系统状态可见性**常驻三处:顶部环境/时间窗、卡片右上角状态 chip、底部全局状态条(灰度中/审批中/失败态必须有明确可视标签)。
