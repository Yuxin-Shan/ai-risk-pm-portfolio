# 阶段 4 设计基线

> **虚构 / 模拟声明：**本项目是个人作品集 Demo，使用抽象业务场景与虚构模拟数据。所有案件、对象、指标、版本、时间与状态仅用于演示产品流程，不代表真实公司、真实生产系统或真实上线结果。
>
> 版本：v0.1（风格样张评审版）｜日期：2026-09-17｜适用范围：阶段 4 全部 14 个冻结界面。

## 1. 设计目标

视觉服务于一句话：**让讲解者能在 5 秒内指出“现在在哪、系统在做什么、谁要确认、结果落到哪里”。**

排序原则：

1. 状态可见性高于装饰性。
2. 任务与证据高于聊天氛围。
3. 演示可讲高于上线级信息完备。
4. 诚实边界高于“看起来像真实生产”。

## 2. 视觉方向

两版样张共用相同布局、组件和语义色，只改变表面 Token：

| 方向 | 深色监控台 | 浅色业务后台 |
|---|---|---|
| 关键词 | 克制、专注、运行态、观测感 | 清晰、可信、对象化、文档感 |
| 背景 | 深蓝黑，不用纯黑 | 冷灰白，不用刺眼纯白铺满 |
| 主色 | 电蓝偏青，局部紫色表示灰度态 | 稳定蓝，局部靛紫表示灰度态 |
| 表面 | 低对比层叠 + 细边框 | 白色卡片 + 冷灰边框 + 极轻阴影 |
| 适合讲解 | “系统如何执行与恢复” | “业务人员如何确认与追溯” |

共同禁止：霓虹发光、玻璃拟态、彩色渐变标题、无意义大面积留白、头像气泡主导、仅靠颜色表达状态。

## 3. 页面骨架

桌面基准为 `1200 × 900`，可向上扩展到 1440；本轮截图固定 1200 宽。

| 区域 | 基准尺寸 | 规则 |
|---|---:|---|
| 一级导航 | 184 px | 固定宽度；「AI 工作台 / 在线风控」分组；当前项有背景、边线与文字三重反馈 |
| 顶部栏 | 64 px | 面包屑、页面标题、演示环境与模拟数据标记、全局动作 |
| 主工作区 | 自适应 | 对话页为消息流；监控页为 12 列网格；列表页为表格 + 详情 |
| 对象侧栏 | 236 px | 对话页固定展示本次生成对象；可收起，窄屏移入 drawer |
| 对话输入 | 72–96 px | 固定在内容底部；说明“Enter 发送 / Shift+Enter 换行” |

最小桌面宽度 1024。低于 1024 时对象栏收起，导航可压缩为图标栏；本项目不把移动端作为演示主场景。

## 4. 色彩 Token

### 4.1 语义色（两主题同义，不同明度）

| 语义 | 深色建议 | 浅色建议 | 用法 |
|---|---|---|---|
| 主操作 / 链接 | `#5B8CFF` | `#2563EB` | 当前导航、主按钮、链接、焦点环 |
| 成功 / 已完成 | `#39D98A` | `#0F9F6E` | 成功、已生效、已完成 |
| 警示 / 待确认 | `#F6C760` | `#B7791F` | 待确认、超时风险、影响面提示 |
| 失败 / 阻断 | `#FF6B78` | `#D63C4A` | 失败、拒绝、不可继续 |
| 处理中 / 执行中 | `#5B8CFF` | `#2563EB` | spinner、进度条、执行中 |
| 灰度中 | `#A78BFA` | `#7C3AED` | 灰度验证、试运行；不能与“处理中”混用 |
| 审批中 | `#F6C760` | `#B7791F` | 待审批包、人工确认中 |
| 暂停 / 停用 | `#8B97AD` | `#667085` | 暂停、不可用、旧参数结果 |

状态必须用 **图标 + 文字 + 颜色**；禁止只出现一个彩点。成功色不用于普通装饰，失败色不用于可逆的取消按钮。

### 4.2 表面与文字

| Token | 深色 | 浅色 |
|---|---|---|
| `--bg` | `#08101F` | `#F3F6FA` |
| `--surface-1` | `#0D1728` | `#FFFFFF` |
| `--surface-2` | `#111E33` | `#F8FAFC` |
| `--surface-3` | `#172640` | `#EEF3F8` |
| `--border` | `#263653` | `#DCE3EC` |
| `--text-1` | `#F4F7FC` | `#172033` |
| `--text-2` | `#A9B5C9` | `#536176` |
| `--text-3` | `#738199` | `#7B8799` |

正文与背景对比度目标至少 4.5:1；大号文字至少 3:1。最终全量页需用自动工具复核，当前颜色仍以样张视觉选择为基准。

## 5. 字体层级

系统字体栈，避免字体 CDN 失败：

```css
font-family: Inter, ui-sans-serif, -apple-system, BlinkMacSystemFont,
  "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif;
```

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---:|---|
| Display | 24 / 32 | 680 | 页面主标题，单页最多一个 |
| H2 | 18 / 26 | 650 | 卡组、详情区标题 |
| H3 | 15 / 22 | 650 | 卡片标题、计划标题 |
| Body | 14 / 22 | 450 | 主要业务内容 |
| Compact | 13 / 18 | 500 | 表格、导航、对象列表 |
| Caption | 12 / 17 | 500 | 辅助信息、时间、字段说明 |
| Mono | 12 / 18 | 550 | 案件号、任务号、版本、时间戳 |

中文不使用全大写；英文小标签可用 `letter-spacing: .04em`。金额、比例、时长使用 `font-variant-numeric: tabular-nums`。

## 6. 间距与几何

- 基础单位 4 px；常用序列 `4 / 8 / 12 / 16 / 20 / 24 / 32`。
- 页面外边距 20–24 px；卡片内边距 16 px；高密表格单元格垂直 10–12 px。
- 控件高度：紧凑 32 px，默认 36 px，主输入 44 px。
- 圆角：按钮 9 px，卡片 12 px，大型容器 14 px；不用药丸形大卡片。
- 边框默认 1 px；深色版主要靠边框分层，浅色版可附加 `0 8px 28px rgba(..., .06)` 极轻阴影。
- 动效 140–220 ms，使用 ease-out；进度变化可动画，状态切换不做弹跳。

## 7. 核心组件

### 7.1 全局组件

- 一级导航、分组标题、当前项、折叠态。
- 页面标题栏、面包屑、全局“作品集演示 / 模拟数据”标签。
- Button：primary / secondary / ghost / danger；完整 disabled 与 loading 状态。
- Status badge：成功、待确认、执行中、失败、灰度中、审批中、暂停。
- Table：固定表头、筛选、空态、加载态、错误态、行选中、批量动作。
- Drawer / Dialog / Tooltip / Toast：Toast 不能承载唯一关键信息。

### 7.2 对话操作台专属组件

- 用户需求块：紧凑右对齐，不做社交头像。
- 执行计划卡：目标、四步计划、预计耗时、确认与改参数。
- 进度块：`当前步骤 / 总步骤 + 状态文字 + 进度条 + 预计剩余时间`。
- 待确认卡：说明影响面、关键参数、确认/改参数/取消；超时后仍原位保留。
- 打断反馈：暂停状态必须可见；旧结果标“基于旧参数”。
- 失败卡：失败步骤、原因、已保留结果、从失败步重试/改参数/换工具/整组重跑。
- 需求无法受理卡：明确“未执行”，给最接近的可行路径，不伪造工具。
- 嵌入证据链：默认折叠；展开显示工具、时间、入参摘要、结果状态。
- 会话对象栏：对象类型、编号、状态、更新时间、跳转入口。

## 8. 状态语言规范

| 状态 | 推荐文案 | 禁止模糊写法 |
|---|---|---|
| 执行中 | `执行中 · 第 2/4 步 · 预计 12 分钟` | `处理中…`（无对象、无进度） |
| 待确认 | `等待你确认；确认前不会继续` | `请稍候` |
| 暂停 | `已暂停 · 已完成结果保留` | `已停止`（无法判断能否续跑） |
| 失败 | `第 2 组失败 · 已完成 1 组保留 · 可从失败步重试` | `执行异常` |
| 审批中 | `待审批包 #P-… · 在线侧尚未生效` | `发布中` |
| 灰度中 | `模拟灰度中 · 10% 演示流量` | `已上线` |
| 无法受理 | `未执行：当前无已授权工具；可生成授权包` | 假装正在执行 |

## 9. 图标与图表

- 图标统一来自 Lucide 线性体系；常规 18–20 px，导航 18 px，空态 24–32 px。
- 图标必须配文字；保存、发布、删除等动作不能只靠图形猜测。
- 图表使用 ECharts；同屏主色不超过 4 个，网格线低对比，tooltip 写明口径。
- 每张含数字的演示页在可见区域放置“模拟数据”标记；图表的标题或脚注再次标记。

## 10. 诚实标注与追溯

三处标注作为阶段 4 后续全量交付的硬规则：

1. **文件头**：文档首屏写明个人作品集与虚构模拟数据。
2. **数据表**：所有数据表/图表标题或脚注写“模拟数据”。
3. **演示页**：顶部固定显示“作品集演示 · 模拟数据”，页脚再写完整说明。

页面后续还必须提供 `页面 ↔ FR ↔ AC` 映射；样张页当前显示 `对话窗口 ↔ FR-07/FR-08 ↔ AC-05/AC-06`，但本轮不提前铺开 14 页总表。

## 11. 启发式自检基线

1. 系统状态可见：执行、暂停、失败、审批、灰度都有常驻状态。
2. 贴近业务语言：使用案件、实验、任务、证据链、待审批包。
3. 用户控制：可确认、改参数、取消、暂停、从失败步重试。
4. 一致性：状态色、对象编号、按钮位置与术语跨页一致。
5. 防错：未授权工具 disabled；高影响动作先确认；待审批不等于生效。
6. 识别优于记忆：会话对象栏持续显示产物；筛选条件可见。
7. 灵活高效：支持自然语言入口，也保留传统表格、筛选和详情页。
8. 克制美观：首屏只有一个主任务焦点；装饰不抢状态信息。
9. 错误恢复：说明失败点、保留结果与下一步。
10. 帮助说明：关键边界就地说明，完整口径进入数据说明和映射文档。

## 12. 样张评审问题

用户只需在深色与浅色之间选择主方向，并指出是否需要从另一版借一个局部特征。布局、内容与状态语义不在两版之间变化，避免选色时误选信息架构。
