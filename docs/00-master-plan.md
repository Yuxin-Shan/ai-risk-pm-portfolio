# 高风险交易调查与处置 Agent —— 完整 PM 作品：主计划

> 作品性质：**个人产品能力作品**。使用抽象业务场景与模拟数据，**不代表曾在原公司负责或上线该产品**。
> 既往项目指标（稽核准确率 85%、执行完整率 70→95%、越权 15→0%、单案约 5min）仅作为「个人经验来源」引用，**不得**写成本作品的上线结果。

## 0. 目标

用 AI 真实实现，完整跑通一名产品经理从**需求收集 → 思考 → 结论 → 交付**的全部环节，留下可被外部认可的实质性文档、PRD、原型与可运行本地 demo。

**通关检验（7 条）**
1. 任何功能都能追溯到具体用户问题
2. 能解释为什么用 Agent，而不是更简单的技术
3. 高风险动作有后端权限 + 人工确认 + 审计
4. 指标不只有模型准确率
5. 有明确 MVP、非目标与产品取舍
6. 假设 / 模拟数据 / 真实经历 严格分开
7. 面对「为什么这样设计」能说明依据与替代方案

## 2. 三方评审协议（每阶段）

- 每轮交付先由 **Honnold 汇总**，再交 **Codex / DSH / Claude** 三方独立评审（只读，互不看答案）。
- 三方各自给出：`通过 / 有条件通过 / 不通过` + 具体问题清单 + 修改建议。
- **达成一致（三方均通过或有条件通过且条件已落实）才进入下一阶段。**
- 分歧由第三家盲审裁决；Honnold 保留少数意见，不按多数票机械决定。
- 评审结论落盘到 `reviews/`，每轮一份，注明 agent、结论、未决分歧。
