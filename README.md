# 风控 · AI 赋能产品 — 项目工作区

> 作品声明:本项目基于抽象业务场景与模拟数据,用于展示产品流程判断能力;不代表作者曾在原公司主导、上线或运营该产品。既往风控经验仅作为问题理解的来源。

---

## 项目定位

- **方向**:AI 赋能风控产品形态(用 AI 做风控),非 Agent 自身安全方向。
- **终点**:一个**可点击的 HTML Demo**。
- **必须包含**:至少 1 个 Agent 示例(如:异步深度调查 Agent)。
- **主轴**:演示可讲(不是上线可信)。

## 阶段推进铁律

1. **每个阶段没清晰,坚决不进入下一阶段。**
2. **发现与上阶段交付物有出入 → 回去修改上阶段文档,保持一致**,并记录变更。
3. 上阶段交付物不完整 = 未 Ready,不评审、不推进。
4. 每个决策用变更记录格式存档,被取代不删除。
