# 指标口径表

> 本文档定义每个指标怎么算。演示中出现的任何数字,都能在这里找到出处。
> 结论先行:**20 个指标**分四组 —— 在线链 8 个、离线链 6 个、排查链 3 个、门禁 3 个。**每个指标必须写明优化方向(下降 / 上升 / 状态),方向不明的不能进表。**

## 一、在线链指标

|---|---|---|---|---|---|---|---|---|
| M-01 | 实时命中率 | 规则引擎判定的命中占比 | 命中笔数 | 总请求笔数 | 1 分钟 | 状态 | 在线日志 | 策略团队 |

| M-04 | 拦截率 | Agent 裁决为拦截的占比 | 拦截笔数 | 已裁决笔数 | 5 分钟 | 状态 | 在线日志 | 策略团队 |
| M-05 | 转人工率 | 因必需工具失败 / 取证超时 / 证据不足而进入待人工介入队列的占比 | 待介入笔数 | 转 Agent 笔数 | 10 分钟 | 下降 | 在线日志 | 策略团队 |

| M-07 | 抽检推翻率 | 人工抽检中推翻 Agent 裁决的占比 | 推翻笔数 | 抽检笔数 | 1 天 | 观察(带护栏) | 抽检记录 | 策略团队 |
| M-17 | 待人工介入积压时长 P90 | 待人工介入队列中案件的等待时长(90 分位) | — | — | 1 小时 | 下降 | 待介入队列 | 策略团队 |

**方向说明:**

| 编号 | 意义 |
|---|---|
| M-01 | 状态量。命中率本身无好坏,用于观测规则覆盖面的变化 |
| M-02 | 下降意味着分流阈值调优后,真正需要深度调查的案子变少 |
| M-03 | 下降意味着工具并发与上下文预聚合生效 |
| M-04 | 状态量。拦截率本身无好坏,须与 M-07 配对看。数值剧烈波动才是信号 |
| M-05 | 下降意味着 Agent 取证能力变强,能自己定性的变多 |
| M-06 | 下降意味着工具稳定性提升 |
| M-07 | 观察指标,配护栏。**降低意味着 Agent 判断质量提升;但持续为 0 要警惕抽检流于形式**。护栏:抽检样本量低于阈值时该指标不可读 |
| M-17 | 下降意味着值守处置效率提升;该指标与 M-05 配对,M-05 下降而 M-17 上升说明处置端积压 |
| M-18 | 上升意味着 Agent 取证过程更完整。"完整"的判定:每步调用均有入参摘要与结果状态,且无未标注的缺失步骤 |
| M-19 | 必须为 0,是门禁项。非 0 则不允许生成待注册包 |
| M-20 | 下降意味着新版本相对基线无退化。关键指标取 M-04(拦截率)与 M-07(抽检推翻率),在实验集上做模拟基线对比 |

## 五、一组需要说明的口径选择

| 项 | 选择 | 原因 |
|---|---|---|
| M-03 用 P95 而非均值 | 时延分布长尾明显,均值会被大量快案掩盖 | 需暴露真实体验的尾部 |
| M-05 分母是"转 Agent 笔数"而非"总命中笔数" | 只有进入调查的案件才可能待人工介入 | 分母必须与分子同域 |
| M-07 时间窗取 1 天而非实时 | 抽检本身是抽样的,短窗口样本量不足 | 小样本率值不可读 |
| M-16 用"成功率"而非"失败率" | 这是能力指标,用正向口径更直观 | 单一事实源,不要同义反转 |
| M-01、M-04 标为状态量 | 命中率与拦截率本身无好坏,须与配对指标同看 | 避免把过程量误当目标量 |
| M-20 用"退化率"而非"提升率" | 门禁关心的是不能变差,退化幅度为正即预警 | 与门禁阈值(≤5%)同向,无需二次换算 |
