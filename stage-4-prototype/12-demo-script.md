1. 打开 `prototype/samples/sample-dialog.html?theme=light&state=empty`，输入“把上周那批转账案件重跑一遍”。
2. 展示受理、待确认计划、确认执行、暂停/继续、追加参数与错误恢复。
3. 指向右栏实时步骤与最新产出，打开静态安全查看态后按 Escape 返回。

## 2. 离线验证链（5 分钟）

1. Agent 配置：修改提示词并保存，展示新版本、旧版本和权限边界。
2. 工具台：注册工具并生成 `AUTH-204` 待审批包；指出审批前指定 Agent 与其他 Agent 均不可调用。
3. 实验管理：运行 `EXPERIMENT-2317`，展示 A/B、样本量、时间窗与四项门禁；切到覆盖不足态说明“不构成验证结论”。
4. 任务队列：制造单条失败，展示其余任务不受影响；失败任务经过重试中转为成功。
5. 证据链：直达 `EVIDENCE-88209`，查看工具、时间、输入摘要、结果、缺失标识及 Agent/案件回溯。
6. 验证报告：四项门禁通过时生成 `REGISTER-4517`；切到失败态展示按钮禁用。

## 3. 在线链（5 分钟）

1. 模型服务打开 `AUTH-204`，由人批准后进入 `approved/called`；回工具台按 `CASE-4517` 查到调用记录。
2. 模型服务打开 `REGISTER-4517`，由人确认注册后进入 `registered/monitored`。
3. 策略引擎切换 v5/v4，展示规则条件、阈值、生效范围、名单与默认“转 Agent 并告警”。
4. 实时监控展示 7 个指标并下钻案件；强调下钻不生成归因。
5. 打开案件详情演示成功调查轨迹；切失败分支展示“不强行裁决，进入待人工介入队列”。
6. 抽检推翻拦截，展示解除管控、记录留存及 `DATASET-RISK-Q3 / CASE-4517` 负样本引用。

## 4. 排查链与收口（2 分钟）

1. 日志回放按结果与耗时筛选，展开 `CASE-4517` 的策略命中、授权工具调用、证据与裁决。
2. 切换日志缺失与超期 URL，展示不补造步骤；指出页面不呈现模型内部推理。
3. 沿固定对象 ID 对账三处衔接；再次声明所有结果均为确定性模拟快照。
